

ai_current_std ( 주파수, 토출압력에 대한 기준전류값 ) ai_oiltemp_std ( 주파수, 토출압력, 외부온도에 대한 기준오일온도 ) Data 만들어 놨습니다. 그리고, 각각의 변수를 넣었을때 기준전류값을 가져오는 SP로 sp_get_current_std 와 각각의 변수를 넣었을때 기준오일온도을 가져오는 SP로 sp_get_oiltemp_std 를 만들어 놨습니다.

좋습니다. 이미 **기준값 테이블과 Stored Procedure(SP)가 만들어져 있다면**, Python에서 가장 가까운 값을 직접 검색할 필요가 없습니다.

기존 rule.py에서 SP를 호출하여 기준전류와 기준오일온도를 가져오도록 변경하면 됩니다.

## 1. 변경할 구조

|분석 항목|Stored Procedure|입력값|반환값|
|---|---|---|---|
|전류평균|sp_get_current_std|주파수, 토출압력|기준전류|
|오일온도|sp_get_oiltemp_std|주파수, 토출압력, 외부온도|기준오일온도|

데이터 흐름은 다음과 같습니다.

`ai_data │ ├── io029 : 주파수 ├── io001 : 토출압력 ├── io048 : 외부온도 (확인 필요) │ ├── sp_get_current_std │ └── ai_current_std │ └── 기준전류 │ └── sp_get_oiltemp_std └── ai_oiltemp_std └── 기준오일온도 │ ▼ ai_analysis`

**주의:** 기존 MEGACOM 데이터에서 io048은 유량계 습도입니다. 외부온도에 해당하는 실제 컬럼을 확인해야 합니다.

## 3. Stored Procedure 호출 함수

SP가 입력 매개변수를 받고 SELECT 문으로 기준값을 반환한다고 가정하면 다음과 같이 작성할 수 있습니다.

def get_current_standard(cursor, frequency, pressure):

  

cursor.execute(

"CALL sp_get_current_std(%s, %s)",

(frequency, pressure)

)

  

row = cursor.fetchone()

  

standard = to_float(row[0]) if row else None

  

# SP가 반환한 결과 집합 정리

while cursor.nextset():

pass

  

return standard

오일온도:

def get_oiltemp_standard(cursor, frequency, pressure, outside_temp):

  

cursor.execute(

"CALL sp_get_oiltemp_std(%s, %s, %s)",

(frequency, pressure, outside_temp)

)

  

row = cursor.fetchone()

  

standard = to_float(row[0]) if row else None

  

while cursor.nextset():

pass

  

return standard

이 코드는 SP가 SELECT로 결과를 반환하는 경우의 예시입니다. OUT 매개변수를 사용한다면 호출 방식이 달라집니다.

## 5. SP 정의 확인

**현재 가장 중요한 것은 SP의 매개변수와 반환 방식입니다.**

MySQL에서 다음 명령을 실행해 주세요.

```
SHOW CREATE PROCEDURE sp_get_current_std;
```

```
SHOW CREATE PROCEDURE sp_get_oiltemp_std;
```

또는 매개변수만 확인하려면 다음 SQL을 사용할 수 있습니다.

```
SELECT
    SPECIFIC_NAME,
    PARAMETER_NAME,
    PARAMETER_MODE,
    DATA_TYPE,
    ORDINAL_POSITION
FROM information_schema.PARAMETERS
WHERE SPECIFIC_SCHEMA = DATABASE()
  AND SPECIFIC_NAME IN (
      'sp_get_current_std',
      'sp_get_oiltemp_std'
  )
ORDER BY SPECIFIC_NAME, ORDINAL_POSITION;
```

이 결과를 확인하면 다음 사항을 정확하게 구현할 수 있습니다.

- 주파수·토출압력·외부온도 입력 순서
- IN, OUT 매개변수 처리
- 기준값 반환 방식
- 기준값이 없는 경우 처리

**SP 정의와 외부온도 컬럼명을 알려주시면, 기존 rule.py에서 전류평균과 오일온도의 기준값을 SP로 조회하고 ai_analysis에 저장하도록 통합할 수 있습니다.**
