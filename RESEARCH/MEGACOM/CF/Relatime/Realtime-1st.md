11호기(`deviceId = R00015`)에 두 가지 모델을 결합합니다.

- **온도 예측 모델:** 10분, 30분, 60분, 120분 뒤의 오일온도를 ℃ 단위로 예측
- **CF 모델:** 각 예측 구간 이내에 80℃, 85℃, 90℃에 도달할 확신도를 계산

## 1. 최종 예측 시스템

```
11호기 과거 데이터 (1분 간격)
             │
             ▼
       16개 특징변수 생성
             │
       ┌─────┴──────┐
       ▼            ▼
  온도 예측 모델    CF 모델
       │            │
  미래 온도 예측   고온 도달 확신도
       │            │
       └─────┬──────┘
             ▼
        최종 경보 판정
             │
             ▼
     MySQL ai_oiltemp 저장
```

현재 확인된 선간전압이 2개이므로 우선 16개 특징변수를 사용합니다. 유량계 총유량은 제외하며, 전류가 0인 학습 행도 제외합니다.

## 3. 추가 학습이 필요한 부분

기존 `cf_11_model.json`은 고온 도달 여부를 예측하는 모델입니다. 따라서 미래 오일온도 예측을 위해 **별도의 회귀 모델을 추가 학습**해야 합니다.

우선 RandomForest 회귀 모델을 사용하겠습니다.

|예측 모델|예측 대상|
|---|---|
|RF-10|정확히 10분 뒤 오일온도|
|RF-30|정확히 30분 뒤 오일온도|
|RF-60|정확히 60분 뒤 오일온도|
|RF-120|정확히 120분 뒤 오일온도|
|CF-10|10분 이내 80·85·90℃ 도달|
|CF-30|30분 이내 80·85·90℃ 도달|
|CF-60|60분 이내 80·85·90℃ 도달|
|CF-120|120분 이내 80·85·90℃ 도달|

RF 모델의 성능은 MAE, RMSE 등으로 평가하고, CF 모델은 Precision, Recall, F1-score 등으로 평가합니다.

## 2. 실시간 예측 방법

예를 들어 1호기의 실시간 데이터가 다음과 같이 입력된다고 가정하겠습니다.

|현재 시각|오일온도|특징값 갱신|CF 예측|
|---|---|---|---|
|10:05:00|75.0℃|실행|실행|
|10:05:05|75.1℃|실행|실행|
|10:05:10|75.2℃|실행|실행|
|10:05:15|75.3℃|실행|실행|
|10:05:20|75.4℃|실행|실행|

이때 1분 기준 특징값은 최근 60초 동안의 데이터를 이용하여 계산합니다.

학습 데이터의 1분 측정값과 의미를 맞추기 위해, 예를 들어 **매 시점의 최근 60초 평균온도**를 사용할 수 있습니다.

단, 과거 학습 데이터가 1분 순간 측정값이라면 평균값으로 바꾸는 것이 반드시 더 좋은 것은 아닙니다. 이 경우에는 학습 데이터와 동일한 측정 방식에 맞춰 최근 1분 대표값을 선택해야 합니다.

5분 온도상승률도 동일한 방식으로 계산합니다.

\[ R_5(t)=\frac{T_{1분}(t)-T_{1분}(t-5분)}{5} \]

여기서 \(T_{1분}(t)\)는 현재 시점에 갱신한 1분 기준 대표온도입니다.

## 5. 추가로 중요한 사항

**예측 구간이 길어질수록 고온 도달 확률은 감소해서는 안 됩니다.**

예를 들어 30분 이내 80℃ 도달 확률이 80%라면, 60분 이내 도달 확률은 적어도 80% 이상이어야 합니다.

수학적으로는 다음 관계가 성립합니다.

\[ \boxed{ P_{10}(80)\leq P_{30}(80)\leq P_{60}(80)\leq P_{120}(80) } \]

또한 같은 예측 구간에서는 다음 관계가 성립해야 합니다.

\[ \boxed{ P(80℃)\geq P(85℃)\geq P(90℃) } \]

따라서 CF 모델을 각각 학습한 후 이러한 관계가 유지되는지 검증하고, 필요하면 확신도를 보정하는 기능도 추가하는 것이 좋습니다.

단, CF 점수는 보정 전에는 엄밀한 확률과 다를 수 있으므로 실제 고온 도달 빈도와 비교하여 확률 보정 및 성능 검증을 수행해야 합니다.
