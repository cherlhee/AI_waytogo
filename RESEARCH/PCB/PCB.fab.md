

# EasyEDA에서 Footprint(PCB 풋프린트) 만들기

EasyEDA에서 **Footprint(풋프린트)**는 PCB에 부품을 장착하기 위한 패드, 홀, 외형선 등을 정의한 것입니다.

JGB37-520 DC 모터용 **6핀 커넥터 풋프린트**를 만드는 경우를 기준으로 설명하겠습니다.

## 1. 풋프린트 생성

EasyEDA Standard 기준입니다.

1. EasyEDA 실행
2. 상단 메뉴에서 **File → New → Footprint** 선택
3. 새로운 풋프린트 편집 화면이 열립니다.
4. 오른쪽 속성창에서 단위를 `mm`로 설정합니다.

[EasyEDA 공식 문서 – Footprint 만들기](https://docs.easyeda.com/en/PCB/Footprint-Manager/index.html?utm_source=chatgpt.com)

## 2. 패드(Pad) 배치

6핀 커넥터를 만들려면 패드 6개가 필요합니다.

예를 들어 **2.0mm 피치의 1열 6핀 커넥터**를 가정하면 다음과 같습니다.

```
          6핀 커넥터

    ┌───────────────────────┐
    │                       │
    │  ○  ○  ○  ○  ○  ○     │
    │                       │
    └───────────────────────┘
       1  2  3  4  5  6

       ← 2.0mm →
       (인접 핀 간격)
```

패드 좌표는 다음과 같이 지정합니다.

|Pad|X(mm)|Y(mm)|
|---|--:|--:|
|1|0|0|
|2|2|0|
|3|4|0|
|4|6|0|
|5|8|0|
|6|10|0|

패드를 선택하고 오른쪽 속성창에서 좌표를 정확하게 입력할 수 있습니다.

## 3. 패드 크기 설정

예시로 다음 값을 사용할 수 있습니다.

|항목|설정값|
|---|---|
|Pad Type|Through Hole|
|Pad Shape|Round|
|Pad Diameter|1.5mm|
|Hole Diameter|0.8mm|
|Pin Pitch|2.0mm|
|Pad Number|1~6|

**주의:** 위 값은 풋프린트 작성 연습용입니다. 실제 PCB 제작에는 사용할 커넥터의 데이터시트에 명시된 홀 크기와 패드 간격을 적용해야 합니다.

## 4. 외형선 그리기

EasyEDA의 `TopSilkLayer`에서 커넥터 외형을 그립니다.

외형선은 실제 커넥터의 크기를 기준으로 작성하며, 패드와 겹치지 않도록 배치합니다.

## 5. 풋프린트 저장

상단 메뉴에서 Save를 선택하고 이름을 입력합니다.

예:

`JGB37_520_CONNECTOR_6P_2.0MM`

저장한 풋프린트는 회로도 심볼과 연결하여 PCB 설계에 사용할 수 있습니다.

---

## 6. JGB37-520 모터 제어보드에 적용

JGB37-520 모터 4개를 연결한다면 다음과 같이 구성할 수 있습니다.

|커넥터|용도|핀 수|
|---|---|---|
|J1|전면 좌측 모터|6핀|
|J2|전면 우측 모터|6핀|
|J3|후면 좌측 모터|6핀|
|J4|후면 우측 모터|6핀|

### 확인할 사항

**JGB37-520 모터에 연결된 커넥터가 어떤 종류인가요?**

- JST-PH 2.0mm 6핀
- JST-XH 2.54mm 6핀
- 기타 6핀 커넥터

커넥터 사진이나 모델명을 알려주시면 **EasyEDA에서 실제 PCB 제작에 사용할 수 있도록 패드 크기, 홀 지름, 좌표, 외형선까지 정확하게 설정하는 방법**을 설명하겠습니다.
